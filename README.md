# dsh-aqua-theme

**玻璃质感主题（glassmorphism）for DeepSeek Harness。**

把顶栏、侧栏、输入框、统计行全部变成磨砂玻璃片，背景叠加粒子鲸鱼、鱼群、网格光点与光标辉光。关掉开关即完全还原原生界面，不改 DSH 任何源码。

---

## 📦 安装

### 方式一：DSH 内直接安装（推荐）

打开 **设置 → 插件 → 添加插件**，输入：

```
https://github.com/thexiaohu/dsh-aqua-theme
```

或输入包名（已发布到 npm 后）：

```
dsh-aqua-theme
```

安装后**完全退出 DSH 再启动**。

### 方式二：脚本安装

```powershell
git clone https://github.com/thexiaohu/dsh-aqua-theme
cd dsh-aqua-theme
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

浏览器版加 `-Profile web`。

脚本**不会覆盖已有安装**：本地已存在时直接复用，保留你的修改。需要重新下载加 `-Force`。

## ✨ 特性

- **玻璃材质** — 模糊半径与不透明度可调，明暗双主题各有配色
- **环境装饰** — 粒子鲸鱼、鱼群、网格光点、光标辉光、悬停下压，均可单独开关
- **鱼群可调** — 数量、尺寸区间（上下限随机）、独立配色与透明度
- **背景双来源** — 渐变背景（色调 + 强度可调）或自定义壁纸（图片 / 视频）
- **配色自由** — 大鱼、中小鱼各一组品牌色 + RGB 圆盘取色器
- **一键开关** — 关闭即完全还原原生界面，无残留

## ⚙️ 参数

打开 **设置 → 通用设置 → 外观 → 主题设置**。

### 玻璃

| 参数 | 范围 | 作用 |
|---|---|---|
| 玻璃背景模糊半径 | 0–40px | 各玻璃面的 `backdrop-filter` |
| 玻璃表面不透明度 | 0–100% | 玻璃填充浓度 |

### 背景

| 参数 | 范围 | 作用 |
|---|---|---|
| 背景来源 | 渐变 / 壁纸 | 切换背景类型 |
| 背景渐变色调 | 0–360° | 渐变背景的色相 |
| 背景渐变强度 | 0–200% | 渐变背景的不透明度 |
| 壁纸模糊度 | 0–40px | 图片壁纸的模糊（仅图片） |
| 壁纸磨砂度 | 0–100% | 壁纸上的半透明罩（仅图片） |
| 视频模糊度 | 0–40px | 视频壁纸的模糊（仅视频） |
| 视频亮度 | 0–100% | 视频壁纸的压暗（仅视频） |

壁纸支持 JPG / PNG / WebP 与 MP4 / WebM / OGG。视频存入 IndexedDB（避免 localStorage 配额溢出）。

### 环境装饰

| 参数 | 范围 | 作用 |
|---|---|---|
| 光标辉光色相角 | 0–360° | 光标辉光的颜色 |
| 小鱼数量 | 0–80 条 | 鱼群数量（另有大鱼 1 条） |
| 鱼尺寸下限 / 上限 | 8–120px | 每条鱼在此区间内随机取尺寸 |
| 大鱼透明度 | 0–100% | 粒子鲸鱼的透明度 |
| 鱼透明度 | 0–100% | 中小鱼的透明度 |

**颜色行**：大鱼颜色 / 中小鱼颜色，各有 2 个品牌色块 + RGB 圆盘取色器。

**开关**：粒子鲸鱼 / 小鱼 / 网格光点 / 光标辉光 / 悬停下压 / 鱼显示在上层。

`鱼显示在上层` 把鱼群从玻璃下方提到上方，鱼不再被玻璃模糊。

## 🧱 层数结构

| z-index | 层 | 效果 |
|---|---|---|
| 0 | 环境背景（插件） | 背景渐变 |
| 1 | 海洋生物（插件） | 鱼群、鲸鱼、网格、气泡 |
| 2 | 壁纸（插件） | 图片 / 视频 + 磨砂罩 |
| 3 | 光标辉光（插件） | 跟随鼠标的光斑 |
| 7 | 边缘渐隐条（插件） | 上下 13px 渐隐 |
| 8 | 顶栏 / 输入框 / 统计行（宿主） | 玻璃卡片 |
| 9 | 侧栏（宿主） | 玻璃卡片 |
| 10 | 海洋生物（开关开启时） | 鱼群上浮到玻璃之上 |

会话文字在 `2`，位于鱼群之上。宿主元素层数保持原值。

## 🐟 鱼群生成

- **大鱼**：固定 1 条，尺寸 = 上限 × 1.6
- **小鱼**：数量可调，每条尺寸在 `[下限, 上限]` 内随机
- **布局**：Mitchell best-candidate（蓝噪声），分布均匀且无格点感
